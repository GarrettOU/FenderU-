## Method

3. Pins: `https://www.pinterest.com/resource/BoardFeedResource/get/` per board (requires the `X-Pinterest-PWS-Handler` header and gzip), retried until the returned count equalled pin_count. Raw JSON kept in the session scratchpad (`feed_<board>.json`, `allpins.json`).
4. Numeric ids: profile `feed.rss` (25 newest), matched by image signature + exact description. Board `.rss` feeds and anonymous pin pages return only obfuscated ids.
